# 使用说明（第一次用先看这个）

> **一句话**：一个字按一次 `F`，只打开口；一句唱完按一次 `Enter`。
> **结束时间不用你打，程序自己算。**

看不懂上面这句没关系，往下看 3 分钟就会了。

---

## 1. 启动

双击技能目录里的 **`启动打轴页.cmd`**，浏览器会自动打开。
窗口别关，关了就停了。

也可以自己在终端里跑：

```bash
cd C:/Users/Administrator/.workbuddy/skills/lyric-tapper-yashu
node server.mjs
```

**端口**：默认 `http://127.0.0.1:8787/`。如果上一次没关干净，端口会自动 +1（8788、8789…），
以窗口里打印的那个地址为准。

---

## 2. 整体流程：三块屏

```
① 载入          →   ② 打轴（花时间的是这步）   →   ③ 校验并交付
拖音频 / 贴歌词       跟着唱，一个字按一下 F        回听、微调、保存
```

三块之间会自动切换，也可以手动来回走：`Esc` 回载入，校验屏左上角「← 回去补打」。

---

## 3. 第一步：载入

| 要做的事 | 说明 |
|---|---|
| 拖入音频 | mp3 / wav / m4a / ogg / flac，**≤25MB**。建议先切好 30–60 秒的片段 |
| 贴歌词 | **一行一句**，标点照常写。标点会挂到前一个字上，不单独占一次按键 |
| 填存档名 | 留空就用音频文件名 |
| 点「开始打轴 →」 | 三样齐了按钮才亮 |

关于歌词：

- **贴过一次就会被记住**，下次打开自动回填，不用再复制粘贴。
- 但记住是按「地址 + 端口」存的，换了端口就读不到 —— 这是浏览器规则，不是坏了。
- 想换歌词：直接改文本框，标签行右边有「清空」按钮（只清歌词，不动存档）。

### 3.1 导入已有项目（接着上次的改）

右边「导入已有项目」列出 `songs/` 里所有存过的轴，**最近保存的在最上面**。
每条显示：名字 · 时长 · 几句/几个字 · 保存时间。条目右上角标「缺音频」的，
说明 `songs/` 里那份 mp3 被删或改名了。

点一条会发生四件事：

| 接回来的东西 | 说明 |
|---|---|
| 音频 | `songs/` 里同名的那段，波形、播放直接可用 |
| 歌词 | 填回文本框（并覆盖「歌词记忆」，免得跟轴对不上） |
| 每个字的开口 | 波形上的橙线、时间轴、表格全部复原 |
| 每句的句尾 | 波形上的青绿线一起回来（只认你按过 `Enter` 的那些） |

然后直接进校验屏，可以播、可以改、可以再存。

- **音频被删了怎么办**：轴照样载入，但停在载入屏不让你进（没声音没法干活）。
  把这首的音频重新拖进左上角的框，主按钮就变成「继续改这份轴 →」。
- 回到载入屏后，按钮会从「开始打轴 →」变成 **「继续改这份轴 →」**，点它不会重建轴，点不会丢。
  一旦你改了歌词，它就退回「开始打轴」并提示「会按新歌词重来」—— 因为字符变了，旧点接不上。
- 列表可以在标签行右边点「刷新」重新读一遍（刚存完的东西不用刷新，回到这屏会自动刷）。

## 4. 第二步：打轴（核心）

### 4.1 一个字按几次键？——**一次**

只按一次，按的是 `F`（不是空格，空格是播放/暂停）。

```
一句有几个字  →  就按几次 F
一句唱完     →  再多按 1 次 Enter（收句，一句只一次）
```

所以「5 个字的句子」= **5 次 F + 1 次 Enter**。
**不是**每个字按两次，也**不需要**给结束时间打点。

> **打完最后一个字，屏幕不会自己跳到下一句。**
> 界面会停在这一句，最后一个字变成浅橙色（表示「点已打好，等你收句」），
> 你把尾音听完、按 `Enter`，它才翻到下一句。
> 这一步是必需的 —— 最后一个字唱多长，全靠这一下 Enter 定。

### 4.2 那你只打了开始时间，结束时间呢？

结束时间由程序推，规则只有一条：

> **一个字的终点 = 下一个字的起点**（但有上限）

| 情况 | 终点取什么 | 实际效果 |
|---|---|---|
| 后面还有字，且间隔 < 1.4 秒 | 下一个字的起点 | 这个字一直亮到下一个字开口，没有缝 |
| 后面还有字，但间隔 ≥ 1.4 秒 | `起点 + 1.4 秒` 就收住 | **中间那块空白自动变成「歌手没唱」** |
| 本句最后一个字 | 你按 `Enter` 那一刻（最长 4.2 秒） | 句尾可以拖得稍长一点 |

这就是为什么你只打「开口」就够了 —— **你打下一个字的时候，上一个字的结束时间就定了。**
唯独句尾不行：句尾后面没有下一个字，只能靠 `Enter` 标一次。

**`Enter` 按在哪一刻，尾音就收到哪一刻。** 所以：
唱完最后一个字别急着按，等声音真的收住了再按。
按早了也没事 —— `Enter` 可以覆盖，挪到正确位置再按一次（见 5.4）。

### 4.3 举个完整例子

一句「把夜点成河」，你实际按的样子：

```
0.0s        0.42   0.85   1.30                        3.10   3.60
 |           |      |      |                           |      |
 F           F      F      F                           F      Enter
 |           |      |      |                           |      |
[ 把 ]     [ 夜 ] [ 点 ] [   成   ] ... 空隙 ...       [ 河 ]
```

（示意图，非等比）

| 字 | 你按了几次 | 起点 | 终点（程序算） | 为什么 |
|---|---|---|---|---|
| 把 | 1 次 `F` | 0.00 | 0.42 | 下一个字 0.42 开口 |
| 夜 | 1 次 `F` | 0.42 | 0.85 | 下一个字 0.85 开口 |
| 点 | 1 次 `F` | 0.85 | 1.30 | 下一个字 1.30 开口 |
| 成 | 1 次 `F` | 1.30 | **2.70** | 下一个字到 3.10 才开口，超过 1.4 秒上限，所以收在 1.30+1.4 |
| 河 | 1 次 `F` | 3.10 | 3.60 | 句尾，`Enter` 收在 3.60 |

「成」后面那段 2.70→3.10 的空白，就是歌手换气的地方 —— **你没做任何事，它自动留白了**。

### 4.4 完整按键序列（照着做）

```
1. 载入音频 + 贴歌词 → 开始打轴
2. 按 空格 开始播放（进打轴屏会自动播，但浏览器常会拦，按一下空格最稳）
3. 听到第一个字开口 → 按 F          ← 第 1 次
4. 听到第二个字开口 → 按 F          ← 第 2 次
5. ……每个字的开口就是一次 F……
6. 最后一个字打完，尾音唱完 → 按 Enter   ← 收句，一句只此一次
7. 自动切到下一句，回到第 3 步
8. 全部打完自动进校验屏
```

第 6 步的细节：打完最后一个字，界面**停在本句不动**，最后一个字变浅橙，
底部提示「尾音唱完再按 Enter 收句」。这时跟着听，声音一收就按 `Enter`。
（如果这一句的最后一个是短音，听到它断掉就按，别等。）

**中途随时可以按空格暂停**，想好了再继续，不影响已经打好的点。

### 4.5 打错了怎么办

**先别急着重来。** 打错分三类，修法完全不一样：

| 错法 | 典型表现 | 一句话修法 |
|---|---|---|
| ① 位置错 | 数量对、顺序对，只是某个字早了/晚了 | 时间轴上微调，最省事 |
| ② 数量错 | 后面整体错位，或两个框挤在一起 | `Backspace` 退，或整句重来 |
| ③ 内容错 | 歌词本身写错了 | **危险**，详见第 5 章 |

完整的抢救流程见下一章 **第 5 章「按错了怎么办」**。

### 4.6 打完之后发现早/晚了 30 毫秒

用**波形正下方的时间轴**改。鼠标只给大概，键盘才给精度：

| 想干什么 | 怎么做 |
|---|---|
| 改某个字的**起点** | 点一下这个字的矩形框（会套上白色外环），按 `←` `→` 调，**一下 1 帧**（约 33 毫秒），按住 `Shift` 是 10 帧 |
| 改某个字的**终点** | 点住框的**右边缘**（出现白色竖条），再按 `←` `→` |
| 只大概挪一下 | 直接拖框的左边或右边，松手就好 |
| 听听这个字 | 点框的中心，会跳过去播这一个字 |
| 换一句看 | `↑` `↓` |

框的规矩：**相邻两个字一上一下交错**（这样两条边不会互相挡住），
左右边颜色会轮换（青绿 / 琥珀）。虚线的框表示这句还是「均分草案」，你第一次动它才会落成真实值。

> 记住这句话：**鼠标给大概，键盘给精确。永远不要指望拖能拖到 1 帧。**

### 4.7 长音怎么办（唯一需要你动「终点」的情况）

分两种，界线是「这个字是不是本句最后一个字」：

| 位置 | 谁决定终点 | 怎么做 |
|---|---|---|
| **句尾最后一个字**（最常见：2 秒、3 秒、5 秒的收尾长音） | 你按 `Enter` 的那一刻 | 打完最后一个 `F` 后**别急**，听尾音收干净了再按 `Enter`。按早了就再按一次覆盖（5.4） |
| **句子中间的字**（比如「爱——」拖 3 秒，后面还有字） | 程序按 1.4 秒上限收住，会提前掐掉 | 点住这个字的右边缘，按住 `→` 往前推，推到声音结束 |

> 判断口诀：**尾巴上那个字交给 `Enter`，中间的长音交给右边缘。**
> 打完句尾那一刻，最后一个字会变成浅橙色 + 底部提示「等内容按 Enter 收句」，
> 就是提醒你：现在按下的 Enter 决定这个字唱多长。

### 4.8 右边那个「捕获」面板是干嘛的

它是给你**验收**用的，打完一句扫一眼就知道打得对不对：

| 你看到 | 意思 | 怎么办 |
|---|---|---|
| 时长条**变黄**（间隔 >1.2 秒） | 这里有个长停顿 | 正常，除非这句本来没停顿 |
| 时长条**变红**（>2.5 秒） | 多半**漏打了一个字** | 回去补 |
| 时长条**变橙**（间隔 <0.1 秒） | 两个点挨太近，可能按快了 | 微调一下 |
| 底部写「未收句」 | 这句还没按 `Enter` | 补一下，否则句尾长度是估的 |

### 4.9 波形上的竖线都是什么（两种颜色）

| 颜色 | 是什么 | 怎么来的 |
|---|---|---|
| **橙色细线**（只到波形中间那截） | 一个字的**开口**时刻 | 每按一次 `F` 画一根 |
| **青绿整条线**（顶头带一小横杠） | 一句的**句尾** | 每按一次 `Enter` 画一根，一句只有一根 |

所以橙线的数量 = 打过的字数，青绿线的数量 = 收过句的句数。一眼就能看出「哪句收了、哪句没收」。

**它们和下面时间轴上「几个字铺满一屏」不是一回事**：波形显示的是整段音频，
时间轴只放大当前这一句。波形上那段**浅色底 + 两条边线**才是这一句的真实长度。
所以同一个字在两个地方位置对不上是正常的，不是画错了。

## 5. 按错了怎么办（急救手册）

打轴是手工活，按错很正常。**关键是先判断错在哪一类**，别一上来就整句重来。

```
第一步永远是：按一下 空格 暂停
                ↓
        数量对不对？（字数和框数一致吗）
        ├─ 对 → ①位置错 → 微调就行，别重来
        └─ 不对 → ②数量错 → 退一个 / 整句重来
```

### 5.1 多按了一下 `F`（这句多出一个点）

**现象**：两个字的框挤在一起（右侧面板有橙条，间隔 <0.1 秒），后面的字整体往前错位。

**按一次 `Backspace`**。它一口气做三件事：

1. 清掉刚才那个点
2. 待打位置退回一格
3. 播放位置自动倒回上一个字之前 0.15 秒

然后重唱这一下就行。

### 5.2 漏了一个字没按

**现象**：某个字的时长条变**红**（>2.5 秒），后面全部错一位。

这是最麻烦的一种，因为错位已经写进后面每个字里了。两个选择：

| 办法 | 代价 |
|---|---|
| **整句重来**：`Shift+Backspace` 或 `R` | 重打一句约 10 秒 —— **推荐** |
| 手工挪：时间轴上把错位的字一个个拖回去 | 短句（≤5 字）可行，长句比重来慢 |

### 5.3 按早了 / 按晚了（差几十毫秒）

**现象**：数量和顺序都对，就是某个字亮早了或亮晚了。

| 范围 | 怎么修 |
|---|---|
| 单个字 | 时间轴点住它的**左边缘**，`←` `→` 调（一下 1 帧 ≈ 33 毫秒） |
| 一整句都偏 | 逐字挪太慢，而目前还不支持整句平移，所以：`R` 重打这一句更快 |
| 整段都偏 | 校验屏拖「整体偏移」滑块（正数延后、负数提前，±200ms 够用） |

> 别为了 30 毫秒去重打一整句 —— 时间轴存在的意义就是这个。

### 5.4 收句收错了（`Enter` 按早或按晚）

**`Enter` 是可以覆盖的**：再按一次，句尾时间就被新的替换掉，不需要撤销。

做法：用 `←` `→` 或点波形把位置挪到正确的地方，**再按一次 `Enter`**。

什么时候都能覆盖 —— 哪怕界面已经翻到下一句，只要你**还没开始打下一句**，
这一次 `Enter` 仍然是给上一句收句的（光标顺序和「你说的是哪一句」不是一回事，这里已经处理好了）。

（注意：如果你退到比第一个字还早的位置，最小会保到「首字 + 0.1 秒」。）

### 5.5 误按了 `Backspace`

退多了而已 —— 那个字的点被清掉了。在正确的时刻**再按一次 `F`** 补回来。

### 5.6 误按了 `Ctrl+Enter`（跳过整句）

剩下没打的字会被按 0.32 秒间隔**估**上去，这些值全是假的。

**怎么认出来**：右侧面板时长条参差不齐、校验屏里这句的逐字时间间隔一模一样。

**怎么修**：打轴屏按 `R` 整句重来，或进校验屏点这一句的「重打」。

### 5.7 误按了 `R` 或 `Shift+Backspace`（整句清空）

**不可撤销。** 这句的所有点都没了，只能重打。

打轴屏里只有这一组键没有后悔药（另一个同样危险的动作是回载入屏改歌词，见 5.10）。
它不是容易误按的键 —— 但真按到了就别浪费时间去翻撤销。

### 5.8 想打点却按了空格（或反过来）

**没有任何数据被改**，只是暂停了（或开始了播放）。再按一次空格继续，接着按 `F` 就行。

按 `F` 时如果处于暂停状态，会记下**当前暂停位置** —— 这是合法用法（听清了再补打），但如果是不小心按的，`Backspace` 退掉即可。

### 5.9 时间轴上拖错了

| 情况 | 后果 |
|---|---|
| 只是**点**了一下边（没拖） | **什么都不会写**，只是选中。这是刻意做的保护 |
| 拖过头了 | 反向拖回去，或用方向键精调 |
| 想撤销整次拖动 | 没有撤销。但值一定在合法范围内（不会压到相邻字），最多位置不对，结构不会坏 |

### 5.10 ⚠️ 打到一半发现歌词有错字

**这是最危险的一个，务必读完。**

回载入屏改完歌词、再点「开始打轴」，程序会**按新歌词重建所有句子，
已经打好的轴全部作废，且不可恢复**。

所以：

- **打之前把歌词核对一遍**：错字、断句、多打的标点。这是唯一真正省事的办法
- 打到一半才发现的，先回打轴屏把这一遍打完 → 校验屏「保存到 songs/」→ 再改歌词重打
- 已有进度时点「开始打轴」，现在会弹确认框：**「重新开始会清空已经打好的轴（不可撤销），继续？」** —— 别习惯性点确定

### 5.11 急救优先级（贴在显示器边上看）

1. **先按空格暂停** —— 别让错误继续累积
2. 看右侧面板：数量对不对？
3. **对** → 位置错 → 时间轴微调，别重来
4. **不对** → 数量错 → `Backspace` 退一个；错位已经扩散就 `R` 整句重来
5. 中途**绝对不要**回载入屏改歌词

## 6. 第三步：校验

打完后自动进来。这里做三件事：**回听、微调、交付**。

| 操作 | 怎么用 |
|---|---|
| `▶ 播当前句` / `Enter` | 只听这一句 |
| `▶ 播全段` / `空格` | 从头听一遍。**中间那行大字会跟着音乐换句**（唱到哪句显示哪句，表格高亮一起走）；暂停时不动，方便你停在某句上看 |
| 点表格任意一行 | 选中这句，下面弹出**逐字 chips**（每个字带时间） |
| 点某个 chip | 选中这个字（会从它前面 0.25 秒开始播，方便听）；按 `←` `→` 微调起点（1 帧 / `Shift` 10 帧） |
| `↑` `↓` | 换句 |
| 「重打」按钮 | 跳回打轴屏，从这句重打 |
| **整体偏移** 滑块 | 如果整段字都亮了但比声音晚一点点，整体往后推（正数延后、负数提前），±200ms 够用 |

> 整体偏移只改输出，不改你打的原始值 —— 拖回去就恢复，可以放心试。

## 7. 交付

校验屏底部三个按钮：

| 按钮 | 干什么 |
|---|---|
| **保存到 songs/** | 存成 `songs/名字.json`，下次能从「导入已有项目」接着改 |
| **复制 lyrics 片段** | 把 `lyrics` 数组直接复制到剪贴板，粘进 MV 技能的 `story.json` 就能用 |
| **下载 JSON** | 下载一份文件，想放哪放哪 |

输出的是这个结构，MV 引擎直接认：

```json
{
  "text": "把夜点成河",
  "start": 0.0,
  "end": 3.6,
  "words": [
    { "w": "把", "t": 0.0,  "e": 0.42 },
    { "w": "夜", "t": 0.42, "e": 0.85 }
  ]
}
```

`t` 是开口时间，`e` 是收住时间（就是你按 `Enter` 或程序推出来的那个）。

## 8. 快捷键速查卡

### 打轴屏

| 键 | 作用 |
|---|---|
| `空格` | 播放 / 暂停 |
| `F` | **打点**（记下这个字的开口） |
| `Enter` | **收句**（一句一次；波形上会多一条青绿线） |
| `Ctrl+Enter` | 跳过本句剩下的字 |
| `Backspace` | 退一个点（并往回倒一点重播） |
| `Shift+Backspace` / `R` | 整句重来 |
| `←` `→` | 有选中边 → 调那条边；没选中 → 挪播放头。**1 帧**，`Shift` 10 帧 |
| `↑` `↓` | 时间轴切上/下一句 |
| `Esc` | 回载入屏 |

### 校验屏

| 键 | 作用 |
|---|---|
| `空格` | 播放 / 暂停 |
| `Enter` | 播当前句 |
| `←` `→` | 有选中字 → 微调；没选中 → 切句 |
| `↑` `↓` | 切句 |
| `Esc` | 回打轴屏 |

## 9. 常见问题

| 现象 | 原因 / 处理 |
|---|---|
| 进去不动 | 浏览器拦了自动播放，**按一下空格** |
| **打完最后一个字，感觉它自己跳到下一句了** | 那是「光标前进」，不是跳句：本句还在等 `Enter` 收句，底部会提示「尾音唱完再按 Enter」。按了 Enter 才真的翻页 |
| 打点没反应 | 焦点在输入框里（比如刚改过存档名），点一下页面再按 |
| 空格没播放，反而打了点 | 你按的是 `F` 吧？`空格` 才是播放 |
| **按错键了怎么办** | **看第 5 章「按错了怎么办」**：位置错就微调，数量错就退一个或整句重来 |
| 两个字的框挤在一起 | 多按了一下 `F`，按一次 `Backspace` 退掉（5.1） |
| 某个字亮了两秒以上 | 多半漏按了一个字，时长条会变红（5.2） |
| 字的亮灭跟声音差一点点 | 校验屏拖「整体偏移」，±30ms 一般就够；单个字用时间轴调（5.3） |
| 收句收早了 | `Enter` 可覆盖，挪到正确位置再按一次（5.4） |
| 长音被提前掐掉 | 点住它的右边缘按 `→` 往前推（见 4.7） |
| 换端口后歌词没了 | 歌词按「地址+端口」存，端口变了读不到，重新贴一次就好 |
| **提示「音频没找到」，但 `songs/` 里 mp3 明明在** | 两种原因：① 那个 cmd 窗口里跑的还是旧服务 → 关掉窗口，重新双击 `启动打轴页.cmd`；② 存档记的是 `xx.MP3`（大写），磁盘上是 `xx.mp3` → 新版会自动对齐，同样要重启一次服务才生效 |
| 波形是空的 | 音频编码浏览器解不了，换 mp3 试试；波形挂了不影响打轴 |
| 拖进度条跳回去 | 服务端的 Range 支持被改坏了，看 `server/routes/audio.mjs` |

## 10. 30 秒上手清单

第一次用，拿这四句练一下（就是载入页的示例歌词）：

```
灯一盏一盏
把夜点成河
我数着浪
数不到你
```

1. 贴进去，点开始打轴
2. 按空格，听到「灯」按 `F`，听到「一」按 `F`……「盏」`F`、「一」`F`、「盏」`F`
3. 这一句唱完，按 `Enter`
4. 看右下角「捕获」面板：5 个字，每条时长条都差不多长 → **对了**
5. 如果某条特别长，说明那个字按早了，`Backspace` 退回去重按

四句都这么打一遍，你就完全会了。
